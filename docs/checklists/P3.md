# P3 hardware checklist: WebSocket live state

Flash firmware and UI (`run -t upload`, then `run -t uploadfs`; uploadfs wipes saved settings, so redo the Network save once).
Use the board's own network (`http://192.168.73.1/`) or the home LAN, whichever you can reach from two or three devices.
Have these devices registered first: a relay (onboard LED on GPIO2, active low is fine), a button input on GPIO4 (pull-up, inverted), a PWM LED on GPIO14.
Tick each row on the NodeMCU; the ESP32 column stays open until the board arrives.

| # | Check | NodeMCU | ESP32 |
|---|-------|---------|-------|
| 1 | Open the page on one device: Dashboard **Live pages** says `1 open` within 3 s and the dot is green | | |
| 2 | Open the page on a second device: both show `2 open`. Open a third: `3 open` | | |
| 3 | Toggle the relay on one page: the other pages follow within 1 s, with no refresh | | |
| 4 | Press the button on the board: ACTIVE / inactive and the change count update on all pages within 1 s, +2 per press and release | | |
| 5 | Drag the PWM slider on one page: the LED dims live while you drag, no error text appears, the final value sticks; other pages show the final value | | |
| 6 | Open a fourth page: it loads and the controls still work (slower updates are fine). The first three keep updating | | |
| 7 | Add a device on one page, then remove it: the other pages show the change without a refresh | | |
| 8 | Turn off one phone's Wi-Fi for 20 s, change the relay from another device, turn Wi-Fi back on: the phone page reconnects by itself and shows the current state | | |
| 9 | Unplug the board with a page open: the dot goes red. Plug it back in: the page recovers by itself when the board is back (no manual refresh) | | |
| 10 | With three pages open and 6 devices registered, Dashboard heap stays above 15 KB free | | |
| 11 | Leave three pages open for 15 minutes, press the button now and then: no reset, still live, heap not shrinking | | |
| 12 | ESP32 only: rows 1 to 11 | n/a | |

Write down any row that fails and what you saw.
