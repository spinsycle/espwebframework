# P6 hardware checklist: dashboard engine (auto layout, manual editor)

Flash firmware and UI (`run -t upload`, then `run -t uploadfs`; uploadfs wipes saved settings, so redo the Network save once).
Use the board's own network (`http://192.168.73.1/`) if the home router is slow to let the board join.
Tick each row on the NodeMCU; the ESP32 column stays open until the board arrives.

Before you start, on the Devices tab have these (nothing needs to be wired except where a row says so):
a relay `r1` (GPIO14), a PWM `p1` (GPIO12), a motor `m1` (speed GPIO13, direction GPIO15; use freq 1000 like `p1`), a servo `s1` (PCA9685 channel 0, or direct on GPIO5 if you remove the other PWM devices), a BME280 or DS18B20 sensor, a button `b1` (GPIO2), and a serial device if you have the loopback wire.
