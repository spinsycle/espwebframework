# P4 hardware checklist: motors, servos, sensors, I2C, serial, buttons

Flash firmware and UI (`run -t upload`, then `run -t uploadfs`; uploadfs wipes saved settings, so redo the Network save once).
Use the board's own network (`http://192.168.73.1/`) if the home router is slow to let the board join.
Start clean: remove every device on the Devices tab first (the old test button on GPIO4 and the LED on GPIO14 would collide with the pins below).
Tick each row on the NodeMCU; the ESP32 column stays open until the board arrives.

## Wiring (NodeMCU GPIO numbers; D-labels in brackets)

| Part | Connection |
|------|------------|
| PCA9685 + BME280 | SDA = GPIO4 (D2), SCL = GPIO5 (D1), 3.3 V, GND. Both share the two wires. Servo power from its own 5 V supply into the PCA9685 V+ terminal; **common GND** with the NodeMCU. |
| DS18B20 | data = GPIO0 (D3) with a **4.7 k resistor from data to 3.3 V**, VCC 3.3 V, GND |
| DC motor driver (3 inputs: ENA, IN1, IN2) | ENA = GPIO14 (D5), IN1 = GPIO12 (D6), IN2 = GPIO13 (D7). Motor supply separate, common GND. |
| Button | GPIO2 (D4) to GND (internal pull-up used) |
| Serial loopback (row 14) | a jumper wire between GPIO12 and GPIO13, motor driver unplugged and the motor device removed |

ESP32 pin numbers differ (I2C is GPIO21 / GPIO22); decide them when the board arrives.

## Checks

| # | Check | NodeMCU | ESP32 |
|---|-------|---------|-------|
| 1 | Devices tab: the Type list offers DC motor, Servo, Sensor, Serial device. Picking Servo + PCA9685 or Sensor + BME280 hides the GPIO pin box | | |
| 2 | I2C card: **Scan bus** lists `0x40 PCA9685 or similar` and `0x76 BME280 / BMP280` (or `0x77`). The pins read SDA GPIO4, SCL GPIO5 | | |
| 3 | Add a DS18B20 sensor on GPIO0: a temperature shows within 6 s. Warm it with your fingers: the value rises on a second open page without a refresh | | |
| 4 | Unplug the DS18B20 data wire: the card changes to "no reading" within about 25 s. Plug it back: the value returns | | |
| 5 | Add a BME280 at the address the scan found: temperature, humidity and pressure look right (room temperature, 20-70 %, 950-1050 hPa). Breathe on it: humidity rises. (A BMP280 shows no humidity: that is correct.) | | |
| 6 | Add a PCA9685 servo, channel 0, address 0x40. It moves to 90 degrees on add. Drag the slider: the servo follows smoothly from 0 to 180 | | |
| 7 | At the two ends, no buzzing or straining. If it buzzes, narrow the pulse range (e.g. 600 and 2300) and re-add; this is the calibration knob. Write down the values that were right for your servo | | |
| 8 | Add a second servo on channel 1 (same board): accepted, and the two move independently | | |
| 9 | Reboot the board: the servos come back at their "At boot" angle, sensors resume reading, the I2C scan still works | | |
| 10 | Try to add a BME280 at the same address: rejected `address_in_use`. Try to add a button on GPIO4: rejected `pin_in_use`. | | |
| 10b | Last, remove every I2C device (servos, BME280), add a button on GPIO4, then press **Scan bus**: it says a device is using the I2C pins, and nothing happens to the button. Remove the button when done | | |
| 11 | Add the motor (speed GPIO14, direction GPIO12, second direction GPIO13). It starts stopped. Slider right: it turns one way, speed follows the slider. Slider left: the other way. STOP stops it. If it turns the wrong way for "forward", re-add with Reverse direction ticked | | |
| 12 | Set the motor to 60 %, then press the board's reset button: after the reboot the motor stays **stopped** | | |
| 13 | Add a button on GPIO2 (pull-up, inverted, long press 800 ms). A quick press adds 2 changes and no long press. Hold for 1 s: `long presses` goes up by exactly 1 per hold, not repeatedly | | |
| 14 | Remove the motor. Add a serial device RX GPIO12, TX GPIO13, 9600 baud, with the jumper between them. Send `hello`: the card shows `hello` as the last line and the lines-received count goes up by 1. A 47-character line works; the box stops you at 47 | | |
| 15 | With sensors, servos and the button all running, Dashboard heap stays above 15 KB free, and does not shrink over 15 minutes | | |
| 16 | Optional (ESP8266): remove every PWM device and the motor, then add a direct-pin servo on GPIO14. It moves, with some jitter that you can live with. With a 1000 Hz PWM device present, adding it is refused `freq_conflict` | | |
| 17 | ESP32 only: rows 1 to 16 | n/a | |

Write down any row that fails and what you saw.
