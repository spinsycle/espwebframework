# P1 hardware checklist (NodeMCU; ESP32 items stay open until that board arrives)

Run on the Windows PC in the repo folder. Order matters: firmware first, then the UI image.
Warning: `uploadfs` replaces the whole filesystem, so it also resets saved network settings to defaults.

1. `python -m platformio run -e nodemcuv2 -t upload`
2. `python -m platformio run -e nodemcuv2 -t uploadfs`
3. `python -m platformio device monitor -b 115200`  (press RESET once)

| # | Check | NodeMCU | ESP32 |
|---|-------|---------|-------|
| 1 | Monitor prints `[espwf] ESP8266 framework 0.0.1`, "no valid network config, using defaults", and `AP 'ESPWF-xxxxxx'` | | |
| 2 | Phone sees Wi-Fi `ESPWF-xxxxxx`; join with password `espframework` | | |
| 3 | Browser opens `http://192.168.4.1/`, dashboard shows uptime, memory, storage, AP with 1 client | | |
| 4 | Dashboard numbers update every ~2 s; status dot is green | | |
| 5 | System tab lists device "Smoke Test", chip, flash size, framework 0.0.1 | | |
| 6 | Network tab: choose "Both", enter your home Wi-Fi SSID and password, Save. Dashboard (after reconnecting) shows Wi-Fi client connected with an IP and RSSI | | |
| 7 | The page opens at the home-network IP from another device on the same Wi-Fi | | |
| 8 | Switch to "Join existing Wi-Fi" only. After applying, the `ESPWF-` network disappears and the board is reachable on the home IP | | |
| 9 | Switch back to "Access point only": the `ESPWF-` network returns, client Wi-Fi shows off | | |
| 10 | Mode "Join existing Wi-Fi" with a WRONG password: after ~30 s the `ESPWF-` AP comes back (recovery), dashboard shows "recovery_ap" via `/api/v1/status` | | |
| 11 | Fix the password from the recovery AP: the board joins, the recovery AP drops | | |
| 12 | Power-cycle the board: it comes back in the last saved mode | | |
| 13 | Reject test: Network tab, set AP channel 99 (or SSID empty). UI shows "Rejected: ... (field)" and nothing changes | | |
| 14 | Turn the home router off for 1 minute, then on: the board rejoins without a restart (reconnection) | | |
| 15 | Restart button on System tab reboots the board and the page comes back | | |
| 16 | Leave it running 30 minutes: heap "free" on the dashboard stays flat (no steady decline) | | |

Report any row that fails with what the monitor printed.
