# P2 hardware checklist: devices

Flash firmware and UI (`run -t upload`, then `run -t uploadfs`; uploadfs wipes saved settings, so redo the Network save once).
Pins below are GPIO numbers: NodeMCU D1 = GPIO5, D2 = GPIO4, D5 = GPIO14, onboard LED = GPIO2 (active low).
Tick each row on the NodeMCU; ESP32 column stays open until the board arrives.

| # | Check | NodeMCU | ESP32 |
|---|-------|---------|-------|
| 1 | Devices tab appears and says "No devices yet" | | |
| 2 | Add relay `led`, pin 2, tick "Active low". Toggle button lights and darkens the onboard LED; the button label follows within 2 s | | |
| 3 | Reload the page and power-cycle the board: `led` is still listed and the LED is OFF after boot | | |
| 4 | Add relay on pin 7: rejected with `pin_reserved`. Add another on pin 2: rejected with `pin_in_use`. Id `Bad Id`: rejected with `bad_id` | | |
| 5 | Relay module on GPIO5 (D1): add it, toggle: relay clicks, correct polarity (tick "Active low" if the module is active-low). The relay does NOT click at power-up | | |
| 6 | Remove the relay: it stays off, the card disappears; the same pin can be added again | | |
| 7 | Button from GPIO4 (D2) to GND: add input, pin 4, pull-up on, "pressed reads low" ticked. Press = ACTIVE, release = inactive, "changes" counts +2 per press-and-release (no extra counts from bounce) | | |
| 8 | Hold the button while resetting the board: no phantom change counted at boot | | |
| 9 | LED + 330 ohm resistor from GPIO14 (D5) to GND: add pwm; the slider dims it smoothly; 0 = off, 100 = full | | |
| 10 | Add a relay on GPIO15: card shows the boot-sensitive warning (do not wire anything to it) | | |
| 11 | Add 6 devices of mixed types: heap stays above 20 KB on the Dashboard and the last-reset line is unchanged | | |
| 12 | Two phones on the page; toggle the relay on one: the other follows within 2 s | | |
| 13 | Leave the Devices tab open for 10 minutes: board does not reset, page stays online | | |
| 14 | ESP32 only: relay on GPIO34 rejected with `pin_input_only`; input on GPIO34 accepted | n/a | |

Write down any row that fails and what you saw.
